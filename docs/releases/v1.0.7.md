Kasumi 1.0.7: bigger libraries.

- Libraries now hold up to 1024 games instead of 256. Big Game Pass libraries on Xbox Cloud Gaming were cut short, and Xbox search could only find games in that first part
- GeForce NOW loads more of a large library
- Xbox Cloud Gaming: all games play since 1.0.6. If a game's picture can't be shown on the 3DS, Kasumi tells you why instead of leaving a black screen

Update from Settings > Updates, or install Kasumi.cia with FBI. Homebrew Launcher users can replace Kasumi.3dsx. Your login, library and settings are kept.
