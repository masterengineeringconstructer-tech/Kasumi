Kasumi 1.0.6: Xbox Cloud Gaming is back, for every game.

- Xbox Cloud Gaming works again, and not just Fortnite: every game plays. Xbox only streams in 720p, so the 3DS now decodes it at half size and shows a steady 30 fps
- Xbox: lower input delay and a quicker start
- Fixed the console crash that paused Xbox in 1.0.4
- Clearer messages when an Xbox game can't be shown on the 3DS
- Fixed a short freeze every 30 seconds in Xbox games. It also helps GeForce NOW and Steam Link whenever Kasumi talks to a server mid-game
- GeForce NOW: Kasumi warns you before launching a game your membership can't play (Performance or Ultimate only) and marks those games in your library
- Steam Link: the PC search is back to 2 seconds
- Reports: a crash no longer loses the log of the run before, and the right crash dump is attached
